# Data Attribution

This project uses **StatsBomb Open Data**.

Source repository:

https://github.com/statsbomb/open-data

StatsBomb's Open Data terms request that published research, analysis or insights state StatsBomb as the data source and use the StatsBomb logo. Their media pack / current brand resources should be consulted before publishing the dashboard externally.

The raw StatsBomb JSON files are **not redistributed in this repository**. They are downloaded locally by `etl/download_wsl_data.py` and excluded from version control.

The code and modelling logic in this repository are separate from the underlying StatsBomb data and do not imply endorsement by StatsBomb / Hudl.
